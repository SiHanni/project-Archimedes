12 정답 데이터의 제작 기준

측정값의 신뢰성은 정답 데이터의 품질에 의존한다. 본 절은 정답 마스크와 정답 태그를 어떤 기준으로 제작하고 검수하였는지 기술한다.

12.1 정답 마스크 (시험항목 2)

구분내용
표본 선정진행상태가 거래 완료이고 고객이 업로드한 상품 이미지가 있는 거래 중, 품목과 배경이 중복되지 않도록 10건을 선정하였다
제작 방식이미지 편집 도구로 귀금속 영역을 수작업 선택하였다. 모델 출력을 참조하지 않고 원본 사진만 보고 제작하였다
라벨링 규칙귀금속 본체만 전경으로 한다. 포장·케이스·저울·보증서·그림자는 배경으로 처리한다. 반지 안쪽 구멍과 귀걸이 내부 구멍은 배경으로 처리한다. 체인은 전 구간을 포함한다
해상도원본의 2배 해상도로 제작하여 경계 화소의 판정 오차를 줄였다. 대조 시 동일 해상도로 정합한다
검수제작 후 원본과 겹쳐 육안 검수하였다. 일치·누락·과다를 3색으로 표시한 대조 이미지를 생성해 재확인하였다
복원 검증본 문서 작성 시 정답 마스크를 대조 이미지로부터 화소 단위로 역복원하여, 기존 답안지의 정답 픽셀 수와 10건 전부 완전 일치함을 확인하였다
구멍 처리 규칙의 영향 반지 내부 구멍을 배경으로 처리하는 규칙은 측정값에 직접 영향을 준다. 구멍을 전경에 포함하면 정답 면적이 수 배로 증가하여 IoU 가 실제보다 높게 산출된다. 본 시험은 구멍을 배경으로 두는 기준을 채택하였으며, 모델 역시 동일 기준으로 구멍을 분리하도록 후처리를 구성하였다.

12.2 정답 태그 (시험항목 1)

구분내용
표본 구성리뷰 100건. 실제 유저 리뷰, 시드 리뷰, 부정 표본 확보용 작성 리뷰로 구성하였다
수집 기간2026-03-09 ~ 2026-08-31 (실제 유저 리뷰 88건 기준)
제외 기준공백 제외 10자 미만인 리뷰는 제외한다. 별점만 남긴 리뷰가 빈 문자열로 저장되어 있다
태그 정의KIND 응대 태도·설명·상담 분위기 / FAST 처리 속도·대기 시간 / PRICE 매입가·시세·금액 만족 / NEGATIVE 불만·실망·부정적 경험
판정 규칙다중 레이블을 허용한다. NEGATIVE 는 다른 태그와 배타적이지 않다. 리뷰에 명시적으로 드러난 것만 부여하며 추측하지 않는다. 해당 태그가 없으면 해당없음으로 둔다
저장 형식알파벳 오름차순 CSV 로 강제한다. 정렬을 강제하여야 문자열 비교만으로 정오 판정이 가능하다
검수모델 예측을 보지 않은 상태에서 분류하였다. 예측을 참조하면 판단이 그쪽으로 기울어 정답지가 오염되고 정확도 수치의 의미가 상실된다
부정 표본의 한계 운영 데이터의 부정 리뷰는 3건에 불과하여 해당 클래스의 재현율을 측정할 수 없었다. 이에 부정 표본 확보를 목적으로 리뷰를 별도 작성하여 정답지에 포함하였으며, 해당 리뷰는 운영 리뷰 테이블에 저장하지 않는다. 최종 정답지의 부정 표본은 5건이다.

13.4 측정 절차

  1. 원본 사진을 외곽선 모드로 처리하여 이진 마스크를 얻는다
  2. 모델 마스크를 정답 마스크와 동일 해상도로 최근접 보간하여 확대한다
  3. 교집합·합집합·누락·과다를 계수한다. IoU = 교집합 ÷ 합집합 × 100
  4. 10건의 IoU 를 산술평균하여 mIoU 를 산출한다
  5. 리뷰별 태그 5종을 정답과 대조해 TP·FP 를 계수한다. Precision = TP ÷ (TP + FP)
결정성 추론에 무작위 요소를 두지 않았다. 동일 입력·동일 가중치·동일 커밋이면 같은 결과가 재현된다. 임계값은 모두 소스에 상수로 고정되어 있으며 실행 시점에 변하지 않는다.
